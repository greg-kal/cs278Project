01 · principles

Voice & feel

The product feels like a friendly notebook, not a feed app. Warm paper background, near-black ink, one terracotta accent. The handwritten Caveat display is the personality — use it sparingly so it stays special.

do

Lean on whitespace

Generous gutters (16–22px) and breathing room between cards. Density is earned, not free.

do

One accent color

Terracotta only for: primary CTAs (sometimes), warning/conflict copy, "your turn" eyebrow text. Never decorative.

don't

Stack display type

Caveat appears at most once per screen — usually the H1. Body text is always Inter.

08 · patterns

Recurring patterns

Time always uses Mono

Clock times, durations, and dates are always JetBrains Mono with tabular-nums. This keeps stacked rows aligned and signals "data". Format: 6:30 PM (12h, space before AM/PM). Duration: 1h 30m. Day chip: 3-letter code + day number.

Joined state

Once a user RSVPs, the "Join" button becomes a ✓ in pill in the same slot. Don't change the card layout.

The 8px screen-edge gutter

Phone screen edges always use 16–22px horizontal padding. Day strip and feed cards sit inside that gutter. The status bar uses 28px (matches iOS conventions).

Conflict / overlap signaling

  • An overlapping card gets a small overlaps soccer pill anchored to the top-right (offset above the card edge).
  • Card border shifts to color-mix(in oklab, var(--accent) 30%, transparent).
  • If user is already RSVPed, a footer banner appears with Join both + Swap actions.

Daily prompt — two flavors

  • Inline (default): dark ink card pinned at top of feed under the day strip. 4-up grid of suggestions. Dismissible via × — does not return that day.
  • Modal sheet: bottom sheet over a dimmed feed. Used only on first-open of the day if user hasn't posted by 11am.

Avatar tone assignment

Tone is deterministic from user id: tones[hash(userId) % 5]. Same user = same tone everywhere in the app, forever.

Empty & loading

  • Skeleton: --soft blocks at card-radius, no shimmer animation needed for v1.
  • Empty illustration: a single emoji glyph in a 88px --soft circle — no custom art for v1.
09 · motion

Motion

Subtle. The product is calm. Default easing is a soft out-cubic; never bouncy.

--m-base 200mscubic(.2,.7,.3,1)buttons, segment toggle, pill on/off
--m-sheet 320mscubic(.2,.8,.2,1)bottom sheet enter/exit
--m-page 280mscubic(.4,0,.2,1)nav push/pop
Reduced motion: respect prefers-reduced-motion — fade only, no slide; sheet appears with opacity 0→1 over 200ms.
10 · accessibility

Accessibility

  • Hit targets ≥ 44×44px. The 32px small button is reserved for inline secondary actions inside cards; never a primary CTA.
  • Contrast. Body text (--ink-2 on --paper) ≥ 4.5:1. --muted meets 3:1 for large/secondary text only — never use it for body copy or for state that must be readable.
  • Color is never the only signal. Conflict pill always carries the word "overlaps". Joined state carries a checkmark, not just a color shift.
  • Focus rings. 2px solid --accent with 2px offset, radius matching the element. Never remove default focus on web/PWA builds.
  • Dynamic type. Inter sizes scale with system text-size setting; Caveat display does not (it's a brand glyph). Cap display growth at +20%.
  • Voiceover labels. Avatar stacks announce as "Going: Maya, Jess, Greg, and 5 more." Time uses spoken format ("six thirty PM"), not raw "6:30p".

12 · token export

Tokens, ready to paste

Drop this into your global stylesheet as the first thing. Everything else in the app reads from these.

/* ─────────── timeline.tokens.css ─────────── */
:root {
  /* surfaces */
  --paper:        #FAF7F2;
  --card:         #FFFFFF;
  --soft:         #F3EFE7;

  /* ink */
  --ink:          #1A1814;
  --ink-2:        #2C2823;
  --muted:        #8A8278;

  /* hairlines */
  --hair:         rgba(26,24,20,0.10);
  --hair-2:       rgba(26,24,20,0.16);

  /* accent (terracotta) */
  --accent:       oklch(64% 0.14 38);
  --accent-soft:  oklch(94% 0.04 50);
  --accent-ink:   oklch(38% 0.10 38);

  /* semantic */
  --good:         oklch(58% 0.13 150);
  --warn:         oklch(72% 0.16 75);

  /* spacing (4px base) */
  --s-1: 4px;  --s-2: 8px;  --s-3: 12px;
  --s-4: 16px; --s-5: 20px; --s-6: 24px;
  --s-8: 32px; --s-10: 40px;

  /* radius */
  --r-sm: 6px;  --r-md: 10px; --r-lg: 14px;
  --r-xl: 18px; --r-sheet: 28px; --r-pill: 999px;

  /* elevation */
  --e-1: 0 1px 0 rgba(20,16,12,.02), 0 8px 24px -16px rgba(20,16,12,.18);
  --e-2: 0 2px 0 rgba(20,16,12,.04), 0 14px 40px -18px rgba(20,16,12,.28);
  --e-sheet: 0 -20px 60px -20px rgba(20,16,12,.35);

  /* motion */
  --m-fast:  120ms ease-out;
  --m-base:  200ms cubic-bezier(.2,.7,.3,1);
  --m-sheet: 320ms cubic-bezier(.2,.8,.2,1);
  --m-page:  280ms cubic-bezier(.4,0,.2,1);

  /* type */
  --font-ui:      'Inter', ui-sans-serif, system-ui, sans-serif;
  --font-display: 'Caveat', cursive;
  --font-mono:    'JetBrains Mono', ui-monospace, Menlo, monospace;
}
